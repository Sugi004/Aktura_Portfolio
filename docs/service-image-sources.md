# Service image sources

Each source photograph is a local 960 × 640 WebP crop downloaded from the Unsplash image CDN for contextual, illustrative use. Service pages pair these photographs with designed workflow illustrations. Captions state that the examples do not represent client work or outcomes. The Unsplash license permits commercial use; it does not grant rights to trademarks, recognizable people, or depicted creative works, so avoid those elements in the selected crop. See the [Unsplash Terms](https://unsplash.com/terms).

Each service also has a matching local `after-<service-id>.svg` mockup in `public/images/services/`. These are original interface illustrations with fictional labels and generic content; they do not depict actual client records or outcomes. The executive example shows a fictional crowded inbox and overlapping calendar before an organized inbox and clear schedule after.
