# Earth texture provenance

`earth-blue-marble.jpg` is a local 2048 × 1024 derivative of NASA Earth Observatory's January global Blue Marble: Next Generation base map (`world.200401.3x5400x2700.jpg`, originally 5400 × 2700).

Source: [NASA Blue Marble: Next Generation — Base Map](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/). NASA describes the page as monthly global composites and lists the original file at 8 km/pixel; NASA Earth Observatory states its Blue Marble imagery is freely available to the public. Credit: NASA Earth Observatory; image by Reto Stöckli, enhancements by Robert Simmon. This texture is used as a geographically grounded visual surface, not as live satellite imagery or live flight data.
